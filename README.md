Roamly — Travel Planning App

About the Project

Roamly is a mobile application that helps travelers plan their trips easily and efficiently.

Problem

Travelers often use multiple apps to search for destinations, book tours, manage tickets, and learn about local cultures.

Solution

Roamly solves this problem by centralizing all travel planning steps in one application.

Main Features

1. Home — Search for destinations, explore popular places, and discover travel recommendations.
2. Tours — Find interesting tours and activities.
3. My Tickets — Keep tickets and booking information in one place.
4. Culture Guide — Learn about local traditions, culture, and attractions.
5. Profile — Manage personal information and account settings.
